# ReliefVue visual theme — asset register v01

## Authority

Geraldine requested richer visuals for the brandbook and future pitch, and then specified the ReliefVue logo, a coral Thailand silhouette and a path from city homes to mountain homes. The concept is user-directed; this execution is a review edition. Existing elephant geometry, Alegreya lettering, Fraunces display and Plex interface typography are preserved.

## Files and uses

- `assets/city_to_mountains_v01.png`: generated decorative 16:9 scene, 1671 × 941 px. Earlier navy concept, retained for provenance. It is not used in the current light guide or a real location, disaster or recipient.
- `assets/pastel_wavescape_v02.png`: light brandbook cover and theme preview derived from Geraldine's supplied pastel wavescape reference. It contains no map or elephant; the geographic outline and selected symbol stay separate so their shapes are not generated or distorted.
- `assets/thailand_outline_v01.svg`: generalized country outline derived from Natural Earth 1:50m admin-0 country geometry. Coral #FF8B86; geographic shape preserved with an equirectangular display projection adjusted at 15° latitude. Not an eligibility boundary or report map.
- `assets/reliefvue_elephant_selected.png`: exact current application logo raster. Keep as a separate layer to avoid generative distortion.
- `assets/path_pattern_v01.svg`: code-native ivory backdrop with decorative purple/coral paths. For explanatory sections; not geographical.
- Eight `assets/icon_*_v01.svg` files: original code-native 32 × 32 icons, rounded 1.65 px stroke, covering reserve, household, wallet, evidence, location, ledger, people and authority. Use visible labels for meaning.
- `theme_v01.css`: presentation layout, palette applications and responsive composition. The cover uses the light wavescape. The identity section displays the original logo and accurate country outline as separate assets.

## Presentation reuse

Use the light wavescape for the opening and major brand moments. Reserve navy for text, ledger sections and a limited number of dividers. Keep private evidence separate from public fund records in diagrams. Keep real UI screenshots legible with neutral backing. Do not overlay busy imagery behind data. The full pitch remains to be authored from the confirmed Colosseum questions and ask.

The Thailand outline is a standalone, generalized national silhouette. It has no province boundaries, pins, households, routes or event coordinates. The wave path is a metaphor for continuity of support; it is not a mapped journey. The reference image's generated Thailand-like shape must not be used as geographic evidence.
